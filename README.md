# Cahier des charges

## Consignes

### Site web Vitrine de votre entreprise 
 
Pour que votre entreprise ait une meilleure visibilité, vous mettrez en place un site internet vitrine qui indiquera ces informations avec au moins **3 pages** : 

- Présentation de l’entreprise 
- Prestations et expertises 
- Références clients et partenaires 

 
Ce site devra être professionnel et valoriser l’entreprise et être fait en HTML et CSS sans intelligence artificielle.  
**Le code devra être commenté par vos soins.**
L’utilisation de git et de Github est obligatoire pour l’hébergement de votre code source. 
Votre dépôt GitHub devra être public.  

 

### Consignes Git  

Afin d’éviter tous les conflits, séparez-vous le travail. 

1 personne par fichier HTML  
1 personne dans le projet travaille sur le fichier CSS
